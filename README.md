# 기록물관리 채용공고 모음

기록물관리전문요원·기록연구사 채용공고를 매일 자동으로 모아
**마감일이 가까운 순서**로 보여주는 홈페이지입니다.

## 구성

| 파일 | 하는 일 |
|---|---|
| `scripts/collect.py` | 공고를 받아와 기록물관리 공고만 골라 저장합니다 |
| `docs/data/jobs.json` | 모은 공고 목록입니다 |
| `docs/index.html` | 홈페이지 화면입니다 |
| `.github/workflows/update.yml` | 매일 한국시간 오전 7시, 오후 1시에 자동으로 실행합니다 |

## 공고 출처

- 공공데이터포털 **공공기관 채용정보 조회서비스** (잡알리오 데이터)

나라일터, 클린아이 잡플러스 등은 해외 서버 접속을 막는 것으로 보여
GitHub 서버에서 바로 수집하기 어렵습니다. 다른 방법을 찾는 대로 추가합니다.

## 검색어 바꾸기

`scripts/collect.py` 위쪽의 `KEYWORDS` 목록에 단어를 넣거나 빼면 됩니다.
